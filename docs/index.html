Customer Churn Prediction Pipeline

How well can we really predict churn?

A LightGBM model, evaluated honestly. Every number below is computed from the repo's 5,000-row sample, and the what-if scorer runs the real 100 trees in your browser.

Open Streamlit appView code
Read this first. The saved model was trained on a 999,999-row dataset that is not in the repo, and its test AUC there was 0.635 (README). Here we only have a 5,000-row sample, possibly overlapping the training data, so the AUC below is likely optimistic. An AUC near 0.6 to 0.7 means the model ranks churners better than chance, but not sharply. F1 on a 9.7% base rate is low by construction.
